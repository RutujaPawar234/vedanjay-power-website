# Client / partner logos

Drop **official, authorized** client logos here to replace the name tiles on
the Projects → "Clients & Partners" wall.

- Filename = the client slug + `.png` (transparent background preferred).
- Example slugs (from `src/data/portfolioData.js` → `CLIENTS`):
  `adani.png`, `tata-power.png`, `jsw.png`, `gail-india-ltd.png`, `sembcorp.png`,
  `hero.png`, `sprng.png`, `juniper.png`, `athena.png`, `mundra-solar.png`, …
- Recommended: ~240×120 px, < 40 KB, logo centered on transparent canvas.

Only use logos you are authorized to display. Do NOT use scraped or
AI-generated logos. Until a file exists, the client's name is shown instead.
